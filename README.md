# Ollama
## Description
A small program to chat with a self hosted Olllama Server. Nothing special.

## Dependencies 
### python >= 3.10
The program was tested with python 3.10; therefore, we recommend to use this version.

## Getting startet
### Installing
You need at least **python version 3.10**
You can use a virtual environment\
\
<code> python -m venv venv </code>\
<code> venv/Scripts/activate </code>

Needed packages install with using *pip*\
<code>pip install -r requirements.txt</code>

### Executing program
You have to define at least these two program arguments:
+ -l --language: Define a language model. Must run on server.
+ -U --URI: The uri of the Ollama server.
